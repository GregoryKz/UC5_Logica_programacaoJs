# UC5 - Lógica de Programação com JavaScript

Este projeto reúne uma série de exercícios práticos de lógica de programação em JavaScript, organizados em arquivos separados por exercício.

## Objetivo

Praticar conceitos fundamentais de:
- variáveis
- operadores
- condições
- estruturas `if`, `else if` e `else`
- lógica de programação
- entrada de dados via `prompt`
- saída no terminal com `console.log`

## Como executar

1. Abra o terminal no projeto.
2. Certifique-se de que o pacote `prompt-sync` está instalado:

```bash
npm install prompt-sync
```

3. Execute qualquer exercício com Node.js:

```bash
node Exercicio01-CadastroSimples.js
```

## Observação

Alguns exercícios foram criados com `prompt-sync` para ler dados do usuário pelo terminal.
